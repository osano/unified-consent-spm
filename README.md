# unified-consent-spm

A Swift Package Manager package that distributes the Osano Unified Consent SDK as a binary library.

## Requirements

- Swift tools version 5.3 or later.
- iOS 13 or later.

## Installation

Add this repository as a Swift Package Manager dependency:

```text
https://github.com/osano/unified-consent-spm
```

The package provides the `UnifiedConsentSDK` library.

## Local use

This repository does not define an executable. Add the package to an iOS application to use the SDK.

## Tests

This repository does not define a test target.
